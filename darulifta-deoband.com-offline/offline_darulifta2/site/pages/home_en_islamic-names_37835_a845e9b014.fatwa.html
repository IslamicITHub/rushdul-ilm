    Title: Regarding name Laiba Anzar (لا ئبہ انظار )

    Question: My daughter name is Laiba Anzar, in urdu I use to write as لائبہ. So I request you to please clear the meaning of this name, the way I use to write in Urdu.

    Answer ID: 37835Posted on: Sep 1, 2020

    Bismillah hir-Rahman nir-Rahim !

    (Fatwa: 567/478/B=1433) Laiba (لائبہ) means thirsty. It also means: a thirsty she-camel. It is better to keep any other good name.

    Allah (Subhana Wa Ta'ala) knows Best

    Darul Ifta,

    Darul Uloom Deoband, India

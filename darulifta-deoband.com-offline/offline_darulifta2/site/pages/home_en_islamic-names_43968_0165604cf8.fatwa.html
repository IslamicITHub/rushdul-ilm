    Title: Baby Girl Name

    Question: I want to keep my daughter's name starting with Sameeha. But I want to add another name after the name Sameeha. Please suggest any suitable addition to this name. What is your opinion about Sameeha Mohammed?

    Answer ID: 43968Posted on: Aug 30, 2020

    Bismillah hir-Rahman nir-Rahim !

    (Fatwa: 363/363/M=1434) If you want to keep your daughter’s name as Sameeha then you may keep it. It is not necessary to add any other name after it. Muhammad should be added with male names. If you want to add some other name then you may keep this name: Sameeha Zahra.

    Allah (Subhana Wa Ta'ala) knows Best

    Darul Ifta,

    Darul Uloom Deoband, India

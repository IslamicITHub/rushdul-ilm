    Title: My name is "Syed Nasser Ahmed", Is this name correct according to Islamic naming convention? Should "Abdul" be added before "Nasser" ?

    Question: As Salaam Alaikum, My name is "Syed Nasser Ahmed", Is this name correct according to Islamic naming convention? Should "Abdul" be added before "Nasser" ? Please Advise.

    Answer ID: 27748Posted on: Aug 31, 2020

    Bismillah hir-Rahman nir-Rahim !

    (Fatwa: 1676/1676/M=1431)

    Your name is correct. There is no need to add Abd before Nasser.

    Allah (Subhana Wa Ta'ala) knows Best

    Darul Ifta,

    Darul Uloom Deoband, India

    Title: Is it correct to use the numbers 786 instead of Bismillahir Rahmanir Rahim?

    Question: Assalamu Alaikum, Is it correct to use the numbers 786 instead of Bismillahir Rahmanir Rahim?

    Answer ID: 4748Posted on: Sep 1, 2020

    Bismillah hir-Rahman nir-Rahim !

    (Fatwa: 438/438=M/1429)

     

    786 is the number of bismillah, it is traditionally written by elders. 786 is written to save bismillah from desecration; therefore there is no wrong in writing it. However, it is better to write bismillah where there is no fear of desecration.

    Allah (Subhana Wa Ta'ala) knows Best

    Darul Ifta,

    Darul Uloom Deoband, India

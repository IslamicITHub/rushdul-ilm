    Title: Now a day's its common practice to change the girls name after marriage from father's name to husband's name, is it halaal?

    Question: Assalaamalikum, Now a day's its common practice to change the girls name after marriage from father's name to husband's name, is it halaal?

    Answer ID: 4450Posted on: Sep 1, 2020

    Bismillah hir-Rahman nir-Rahim !

    (Fatwa: 416/416=M /1429)

     

    Islamically there is no poof for the custom of changing names after marriage which is in practice these days. A girl should continue her name the same which has bee before or the time marriage. Yes, it is right to change or modify the name if there is any fault as per the meaning. It is not suitable to change the name of a girl from her father to the name of her husband as fashion.

    Allah (Subhana Wa Ta'ala) knows Best

    Darul Ifta,

    Darul Uloom Deoband, India
